## 1. 接口规范

### 1.1 请求格式

**Header**:
```
Content-Type: application/json
Authorization: Bearer {token}  // 需要认证的接口
```

**Body**: JSON格式

### 1.2 响应格式

**成功响应**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    // 响应数据
  }
}
```

**错误响应**:
```json
{
  "code": 400,
  "message": "错误信息",
  "data": null
}
```

### 1.3 状态码说明

| 状态码 | 说明 | 场景 |
|-------|------|------|
| 200 | 成功 | 请求成功 |
| 400 | 参数错误 | 参数校验失败 |
| 401 | 未授权 | Token无效或过期 |
| 403 | 无权限 | 没有操作权限 |
| 404 | 资源不存在 | 找不到资源 |
| 500 | 服务器错误 | 内部错误 |

### 1.4 分页格式

**请求参数**:
```
?page=1&pageSize=20
```

**响应格式**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "data": [...],
    "total": 100,
    "page": 1,
    "pageSize": 20,
    "totalPages": 5
  }
}
```

## 2. 认证模块 (Auth)

### 2.1 微信登录

**接口**: `POST /auth/wechat-login`  
**描述**: 微信小程序一键登录  
**认证**: 不需要

**请求参数**:
```json
{
  "code": "string  // 微信登录凭证"
}
```

**响应数据**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "userInfo": {
      "id": "1234567890123456",
      "openid": "oXXXX1234567890",
      "nickname": "微信用户",
      "avatar": "https://xxx.com/avatar.jpg"
    }
  }
}
```

**业务逻辑**:
1. 调用微信接口用 code 换取 openid
2. 根据 openid 查询用户，不存在则创建新用户
3. 生成 JWT Token（有效期7天）
4. 首次登录自动创建邀请码（幂等）
5. 返回 Token 和用户信息

**错误码**:
- `400`: code 无效
- `500`: 微信接口调用失败

### 2.2 机构登录

**接口**: `POST /auth/institution-login`  
**描述**: 机构账号密码登录  
**认证**: 不需要

**请求参数**:
```json
{
  "username": "string  // 用户名",
  "password": "string  // 密码"
}
```

**DTO验证规则**:
```typescript
class InstitutionLoginDto {
  @IsNotEmpty({ message: '用户名不能为空' })
  @IsString()
  username: string;

  @IsNotEmpty({ message: '密码不能为空' })
  @MinLength(6, { message: '密码至少6位' })
  password: string;
}
```

**响应数据**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "userInfo": {
      "id": "1234567890123456",
      "openid": "institution_xxx",
      "nickname": "机构账号",
      "avatar": "",
      "institutionId": "2345678901234567"
    }
  }
}
```

**业务逻辑**:
1. 验证用户名和密码（密码使用 bcrypt 加密）
2. 查询用户关联的机构列表
3. 生成 JWT Token（包含 userId 和 institutionId）
4. 返回 Token 和当前机构信息（`userInfo.institutionId`）

**错误码**:
- `401`: 账号不存在或密码错误
- `401`: 机构账号已冻结

### 2.2.1 微信手机号登录（机构/教师）

**接口**: `POST /auth/phone-login`  
**描述**: 机构管理员或教师通过微信手机号快捷登录  
**认证**: 不需要

**请求参数**:
```json
{
  "code": "wx-phone-code",
  "type": "institution"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | string | ✅ | 微信手机号授权 code |
| type | string | ✅ | `institution` 或 `teacher` |

**响应数据（机构登录）**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOi...",
    "userInfo": {
      "id": "1234567890123456",
      "openid": "institution_xxx",
      "nickname": "机构账号",
      "avatar": "",
      "institutionId": "2345678901234567"
    }
  }
}
```

**响应数据（教师登录）**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOi...",
    "userInfo": {
      "id": "1234567890123456",
      "openid": "teacher_xxx",
      "nickname": "张老师",
      "avatar": "",
      "teacherId": "3456789012345678",
      "institutionId": "2345678901234567"
    }
  }
}
```

**业务逻辑**:
1. 用微信手机号授权 code 换取手机号
2. 根据 `type` 校验账号是否已绑定机构或教师身份
3. 机构/教师所属机构若被冻结，则拒绝登录
4. 生成 JWT Token，并返回 `institutionId` / `teacherId`

## 3. 机构模块 (Institution)

### 3.1 创建机构（入驻申请）

**接口**: `POST /institution`  
**描述**: 机构提交入驻申请  
**认证**: 不需要（入驻时创建账号）

**请求参数**:
```json
{
  "name": "某某艺术培训中心",
  "logo": "https://xxx.com/logo.jpg",
  "introduction": "专注儿童艺术教育10年...",
  "province": "北京市",
  "city": "北京市",
  "district": "朝阳区",
  "address": "xxx路xxx号",
  "latitude": 39.9042,
  "longitude": 116.4074,
  "contact_phone": "010-12345678",
  "contact_person": "张三",
  "business_hours": "周一至周日 9:00-21:00",
  "category_ids": ["art", "music"],
  "license_no": "91110000123456789X",
  "license_img": "https://xxx.com/license.jpg",
  "legal_person": "张三",
  "registered_capital": "100万元",
  "username": "test_institution",
  "password": "123456",
  "real_name": "张三"
}
```

**DTO验证规则**:
```typescript
class CreateInstitutionDto {
  @IsNotEmpty({ message: '机构名称不能为空' })
  @IsString()
  name: string;

  @IsOptional()
  @IsString()
  logo?: string;

  @IsOptional()
  @IsString()
  introduction?: string;

  @IsNotEmpty({ message: '省份不能为空' })
  @IsString()
  province: string;

  @IsNotEmpty({ message: '城市不能为空' })
  @IsString()
  city: string;

  @IsNotEmpty({ message: '区县不能为空' })
  @IsString()
  district: string;

  @IsNotEmpty({ message: '详细地址不能为空' })
  @IsString()
  address: string;

  @IsOptional()
  @IsNumber()
  latitude?: number;

  @IsOptional()
  @IsNumber()
  longitude?: number;

  @IsNotEmpty({ message: '联系电话不能为空' })
  @IsString()
  contact_phone: string;

  @IsOptional()
  @IsString()
  contact_person?: string;

  @IsOptional()
  @IsString()
  business_hours?: string;

  @IsOptional()
  @IsArray()
  category_ids?: string[];

  @IsNotEmpty({ message: '营业执照号不能为空' })
  @IsString()
  license_no: string;

  @IsNotEmpty({ message: '营业执照图片不能为空' })
  @IsString()
  license_img: string;

  @IsOptional()
  @IsString()
  legal_person?: string;

  @IsOptional()
  @IsString()
  registered_capital?: string;

  @IsNotEmpty({ message: '用户名不能为空' })
  @IsString()
  username: string;

  @IsNotEmpty({ message: '密码不能为空' })
  @MinLength(6, { message: '密码至少6位' })
  password: string;

  @IsOptional()
  @IsString()
  real_name?: string;
}
```

**响应数据**:
```json
{
  "code": 200,
  "message": "success",
  "data": "2345678901234567"  // 机构ID
}
```

**业务逻辑**:
1. 验证机构名称和营业执照号唯一性
2. 创建用户账号（密码加密存储）
3. 创建机构记录（audit_status = 'pending'）
4. 建立用户与机构的关联（role = 'owner'）
5. 事务提交，返回机构ID

**错误码**:
- `400`: 机构名称已存在
- `400`: 营业执照号已存在
- `400`: 用户名已存在

### 3.4 更新机构信息

**接口**: `PUT /institution/:id`  
**描述**: 更新机构信息  
**认证**: 需要 JWT Token + 机构权限

**路径参数**:
- `id`: 机构ID

**请求参数**:
```json
{
  "logo": "https://xxx.com/new-logo.jpg",
  "introduction": "更新后的简介...",
  "contact_phone": "010-87654321",
  "business_hours": "周一至周日 8:00-22:00"
}
```

**响应数据**:
```json
{
  "code": 200,
  "message": "success",
  "data": true
}
```

**业务逻辑**:
1. 验证用户是否有该机构的操作权限
2. 检查审核状态，已通过的机构不允许修改资质信息（营业执照、法人等）
3. 更新允许修改的字段
4. 返回更新结果

**敏感字段限制**（已审核通过后不可修改）:
- `license_no` - 营业执照号
- `license_img` - 营业执照图片
- `legal_person` - 法人
- `registered_capital` - 注册资本

**错误码**:
- `403`: 无权限操作
- `400`: 已审核通过的机构不允许修改资质信息
- `404`: 机构不存在

### 3.6 查询附近机构

**接口**: `GET /institution/nearby`  
**描述**: 根据地理位置查询附近的机构  
**认证**: 不需要

**请求参数**:
```
?latitude=39.9042
&longitude=116.4074
&radius=5
&category_ids=art,music
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| latitude | number | 是 | 纬度 |
| longitude | number | 是 | 经度 |
| radius | number | 否 | 搜索半径（单位：公里，默认5） |
| category_ids | string | 否 | 类目筛选（逗号分隔） |

**响应数据**:
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": "2345678901234567",
      "name": "某某艺术培训中心",
      "logo": "https://xxx.com/logo.jpg",
      "introduction": "专注儿童艺术教育10年...",
      "province": "北京市",
      "city": "北京市",
      "district": "朝阳区",
      "address": "xxx路xxx号",
      "latitude": 39.9042,
      "longitude": 116.4074,
      "contact_phone": "010-12345678",
      "category_ids": ["art", "music"],
      "distance": 2.5,
      "rating_avg": 4.8
    }
  ]
}
```

**业务逻辑**:
1. 使用 PostgreSQL PostGIS + `distance_km()` 计算球面距离
2. 筛选指定半径内的机构
3. 按距离升序排序
4. 仅返回已审核通过的机构

**距离计算公式**:
```sql
distance_km(location, :longitude, :latitude) AS distance
```

### 3.9 审核机构（平台管理员）

**接口**: `PUT /institution/:id/audit`  
**描述**: 平台管理员审核机构入驻申请  
**认证**: 需要 JWT Token + 管理员权限

**路径参数**:
- `id`: 机构ID

**请求参数**:
```json
{
  "status": "approved",
  "remark": "审核通过"
}
```

**DTO验证规则**:
```typescript
class AuditInstitutionDto {
  @IsNotEmpty()
  @IsIn(['approved', 'rejected', 'frozen'])
  status: string;

  @IsOptional()
  @IsString()
  remark?: string;
}
```

**响应数据**:
```json
{
  "code": 200,
  "message": "success",
  "data": true
}
```

**业务逻辑**:
1. 验证管理员权限
2. 更新机构审核状态
3. 记录审核备注
4. 发送通知（预留）

**错误码**:
- `403`: 无管理员权限
- `404`: 机构不存在

```

  ↓ 通过

pending（待审核）
  ↓ 拒绝
rejected（已拒绝）
  ↓ 重新提交
pending（待审核）
```
