# 第二页：市场痛点分析

## 行业痛点：三方困局亟待破解

### 👨‍👩‍👧 家长之痛
- **信息碎片化**：培训机构众多，查找课程信息困难
- **决策成本高**：不了解机构真实情况，难以做出选择
- **预约体验差**：预约试听流程繁琐，沟通成本高
- **进度不透明**：无法实时掌握孩子学习进度

### 🏫 机构之痛
- **运营成本高**：人工管理课程、教师、教室效率低下
- **获客难度大**：缺乏精准获客渠道，营销成本居高不下
- **管理工具缺**：排课冲突频发，资源调度混乱
- **口碑难建立**：缺乏有效的评价展示和口碑传播机制

### 👨‍🏫 教师之痛
- **排课混乱**：课程安排不透明，时间冲突频发
- **考勤繁琐**：学员签到统计耗时耗力
- **沟通低效**：与家长沟通缺乏统一渠道

```
邀请人生成邀请码 → 新用户用码立减 → 邀请人按完课进度返现
```

### 核心规则
| 要素 | 说明 |
|------|------|
| 🎫 **通用邀请码** | 微信登录即生成，全平台通用 |

| 🔓 **解锁机制** | 按完课进度解锁，100%完课解锁全额 |

### 三方收益
| 角色 | 收益 |
|------|------|
| 🙋 **邀请人** | 好友完课解锁返现，可提现或抵扣 |

# 第十页：邀友返现案例演示

## 邀友返现实战案例

### 案例场景
**机构A**：少儿美术基础课，原价2000元，返现比例10%

### 非获客用户邀请案例
> 用户甲（未报任何课程）邀请新用户丙报名

**计算过程**：
1. 返现总额 = 2000 × 10% = **200元**
2. 用户甲设置让利50%，新用户立减 = 200 × 50% = **100元**
3. 新用户丙实付 = 2000 - 100 = **1900元**
4. 用户甲实际返现 = 200 - 100 = **100元**

**解锁过程**：
- 完课50% → 解锁50元（达到50元提现门槛）
- 完课100% → 解锁剩余50元
- 累计可提现 **100元**

### 核心价值
✅ **零门槛参与**：非获客用户也能生成邀请码赚收益
✅ **真实完课保障**：按实际完课进度解锁，防止刷单
✅ **微信零钱提现**：满50元即可提现，无手续费
