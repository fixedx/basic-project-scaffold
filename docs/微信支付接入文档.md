# 微信支付接入文档

## 一、概述

本文档描述了如何在 Interest Class 项目中接入微信支付功能。

### 支付流程

```
用户下单 → 跳转支付页面 → 调用预支付接口 → 唤起微信支付 → 支付回调 → 更新订单状态
```

### 支付特性

- 支付倒计时：订单创建后有 30 分钟的支付时效
- 自动取消：超时未支付的订单将自动取消
- 支付方式：支持微信支付和线下支付

## 二、环境配置

### 1. 微信支付商户号申请

1. 访问 [微信支付商户平台](https://pay.weixin.qq.com/) 注册商户号
2. 完成商户认证和资质审核
3. 获取以下配置信息：
   - 商户号 (mch_id)
   - API 密钥 (API v3)
   - 商户证书序列号
   - 商户私钥

### 2. 小程序关联

1. 在 [微信公众平台](https://mp.weixin.qq.com/) 登录小程序账号
2. 进入「微信支付」→「关联商户号」
3. 确认商户号与小程序的关联

### 3. 后端环境变量配置

在 `interest-class-server/.env` 文件中添加以下配置：

```env
# 微信支付配置
WECHAT_APP_ID=wxXXXXXXXXXXXXXXXX           # 小程序 AppID
WECHAT_MCH_ID=1234567890                   # 商户号
WECHAT_MCH_SERIAL_NO=XXXXXXXX              # 商户证书序列号
WECHAT_MCH_PRIVATE_KEY_PATH=./certs/apiclient_key.pem  # 商户私钥文件路径
WECHAT_MCH_API_V3_KEY=your-api-v3-key      # API v3 密钥（32位）
WECHAT_NOTIFY_URL=https://your-domain.com/api/payment/notify  # 支付回调地址（可选，默认使用 DOMAIN 配置）
```

### 4. 密钥文件配置

**商户私钥通过文件路径方式配置**，支持绝对路径和相对路径（相对于项目根目录）。

**推荐目录结构**：

```
interest-class-server/
├── certs/                          # 证书目录（已加入 .gitignore）
│   ├── apiclient_key.pem           # 商户私钥
│   └── wechat_public_key.pem       # 微信平台公钥（用于验签）
├── .env
└── ...
```

**配置步骤**：

1. 创建 `certs/` 目录
2. 将商户私钥文件放入 `certs/apiclient_key.pem`
3. 确保 `certs/` 目录已加入 `.gitignore`

```bash
# 创建证书目录
mkdir -p certs

# 确保已加入 .gitignore
echo "certs/" >> .gitignore
```

**安全提示**：
- ✅ 密钥文件不要提交到代码仓库
- ✅ 生产环境建议使用绝对路径或秘密管理服务

## 四、前端调用

### 1. 跳转到支付页面

```typescript
// 报名成功后跳转到支付页面
uni.redirectTo({
  url: `/pages/order-pay/index?id=${orderId}`,
})
```

### 2. 调用微信支付

```typescript
import { paymentApi } from '@/api/payment'

// 获取预支付参数
const prepayResult = await paymentApi.prepay({
  order_id: orderId,
})

// 调用微信支付（仅小程序环境）
// #ifdef MP-WEIXIN
uni.requestPayment({
  provider: 'wxpay',
  timeStamp: prepayResult.timeStamp,
  nonceStr: prepayResult.nonceStr,
  package: prepayResult.package,
  signType: prepayResult.signType,
  paySign: prepayResult.paySign,
  success: () => {
    // 支付成功
    uni.redirectTo({
      url: `/pages/order-detail/index?id=${orderId}`,
    })
  },
  fail: (err) => {
    if (err.errMsg?.includes('cancel')) {
      // 用户取消
    } else {
      // 支付失败
    }
  },
})
// #endif
```

## 五、订单超时处理

### 1. 订单创建时设置过期时间

```typescript
// order.service.ts
const PAY_TIMEOUT_MINUTES = 30; // 支付超时时间（可配置）
const expireAt = new Date(Date.now() + PAY_TIMEOUT_MINUTES * 60 * 1000);

const order = this.orderRepository.create({
  // ...其他字段
  expire_at: expireAt,
});
```

### 2. 定时任务自动取消过期订单

建议使用 NestJS 的 `@nestjs/schedule` 模块实现定时任务：

```typescript
import { Cron, CronExpression } from '@nestjs/schedule';

@Injectable()
export class OrderScheduler {
  @Cron(CronExpression.EVERY_MINUTE)
  async cancelExpiredOrders() {
    await this.orderRepository
      .createQueryBuilder()
      .update()
      .set({ 
        status: 'cancelled',
        cancelled_at: new Date(),
      })
      .where('status = :status', { status: 'pending' })
      .andWhere('expire_at < :now', { now: new Date() })
      .execute();
  }
}
```

## 六、注意事项

### 1. 安全性

- **私钥保护**：商户私钥必须严格保密，不要提交到代码仓库
- **回调验签**：生产环境必须验证微信回调的签名
- **HTTPS**：回调地址必须使用 HTTPS

### 2. 测试

- 微信支付提供沙箱环境，可用于开发测试
- 本项目在未配置微信支付参数时会返回模拟数据

### 3. 金额处理

- 微信支付金额单位为「分」
- 后端在调用微信接口时需要将「元」转换为「分」：`Math.round(amount * 100)`

### 4. 退款

退款功能需要额外实现，调用微信退款接口：

```
POST https://api.mch.weixin.qq.com/v3/refund/domestic/refunds
```

## 七、常见问题

### Q1: 支付时提示「商户号与appid不匹配」

**原因**：商户号未与小程序关联

**解决**：
1. 登录微信支付商户平台
2. 进入「产品中心」→「AppID账号管理」
3. 关联小程序的 AppID

### Q2: 支付回调未收到

**原因**：
1. 回调地址不可访问
2. 回调地址未使用 HTTPS
3. 服务器未正确响应

**解决**：
1. 确保回调地址公网可访问
2. 配置 HTTPS 证书
3. 检查服务器日志

### Q3: 签名验证失败

**原因**：私钥或证书序列号配置错误

**解决**：
1. 重新下载商户证书
2. 检查私钥格式（注意换行符）
3. 确认证书序列号正确
