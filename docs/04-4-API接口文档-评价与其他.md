## 1. 评价模块 (Review)

### 1.1 创建评价

**接口**: `POST /review`  
**描述**: 家长评价课程（订单完成后可评价）  
**认证**: 需要 JWT Token (家长用户)

**请求参数**:
```json
{
  "order_id": "7890123456789012",
  "course_id": "3456789012345678",
  "institution_id": "2345678901234567",
  "rating": 5,
  "content": "老师非常专业，孩子很喜欢，教室环境也很好！",
  "images": [
    "https://xxx.com/review-1.jpg",
    "https://xxx.com/review-2.jpg"
  ]
}
```

**DTO验证规则**:
```typescript
class CreateReviewDto {
  @IsNotEmpty({ message: '订单ID不能为空' })
  @IsString()
  order_id: string;

  @IsNotEmpty({ message: '课程ID不能为空' })
  @IsString()
  course_id: string;

  @IsNotEmpty({ message: '机构ID不能为空' })
  @IsString()
  institution_id: string;

  @IsNotEmpty({ message: '评分不能为空' })
  @IsInt()
  @Min(1, { message: '评分最低1分' })
  @Max(5, { message: '评分最高5分' })
  rating: number;

  @IsNotEmpty({ message: '评价内容不能为空' })
  @IsString()
  @MinLength(10, { message: '评价内容至少10个字' })
  @MaxLength(500, { message: '评价内容最多500个字' })
  content: string;

  @IsOptional()
  @IsArray()
  images?: string[];
}
```

**响应数据**:
```json
{
  "code": 200,
  "message": "success",
  "data": "8901234567890123"
}
```

**业务逻辑**:
1. 验证订单存在且属于当前用户
2. 验证订单状态为 paid（已支付）
3. 验证该订单未被评价过（一个订单只能评价一次）
4. 创建评价记录（默认可见 is_visible = true）
5. 更新课程评分：
   ```typescript
   rating_avg = (rating_avg × rating_count + new_rating) / (rating_count + 1)
   rating_count = rating_count + 1
   ```

**错误码**:
- `403`: 无权限操作
- `400`: 订单不存在或未支付
- `400`: 该订单已评价过

**接口**: `POST /banner`  
**描述**: 管理员创建轮播图

  link_type: string;

  link_id?: string;

  @IsOptional()
  @IsDateString()
  start_time?: string;

  @IsOptional()
  @IsDateString()
  end_time?: string;

## 4. OSS模块 (文件上传)

### 4.1 生成上传凭证

**接口**: `POST /oss/generate-upload-token`  
**描述**: 生成OSS上传凭证（STS临时授权）  
**认证**: 需要 JWT Token

**请求参数**:
```json
{
  "file_type": "image",
  "file_name": "avatar.jpg"
}
```

**DTO验证规则**:
```typescript
class GenerateUploadTokenDto {
  @IsNotEmpty({ message: '文件类型不能为空' })
  @IsIn(['image', 'video', 'document'])
  file_type: string;

  @IsNotEmpty({ message: '文件名不能为空' })
  @IsString()
  file_name: string;
}
```

**响应数据**（阿里云OSS）:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "provider": "aliyun",
    "access_key_id": "STS.xxx",
    "access_key_secret": "xxx",
    "security_token": "xxx",
    "bucket": "interest-class",
    "region": "oss-cn-beijing",
    "upload_path": "uploads/images/2026/01/17/xxx.jpg",
    "expiration": "2026-01-17T11:00:00.000Z"
  }
}
```

**响应数据**（腾讯云COS）:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "provider": "tencent",
    "tmp_secret_id": "xxx",
    "tmp_secret_key": "xxx",
    "session_token": "xxx",
    "bucket": "interest-class-xxx",
    "region": "ap-beijing",
    "upload_path": "uploads/images/2026/01/17/xxx.jpg",
    "expiration": 1705484400
  }
}
```

**业务逻辑**:
1. 根据配置选择云服务商（阿里云/腾讯云）
2. 生成唯一文件路径：`uploads/{file_type}/{year}/{month}/{day}/{uuid}.{ext}`
3. 调用云服务API生成STS临时凭证（有效期1小时）
4. 返回上传凭证信息

**前端使用流程**:
1. 调用接口获取上传凭证
2. 使用凭证直传OSS
3. 上传成功后拼接完整URL：`https://{bucket}.{region}.aliyuncs.com/{upload_path}`

**错误码**:
- `500`: OSS服务异常

### 7.1 添加宝贝

**接口**: `POST /child`  
**描述**: 家长添加宝贝信息  
**认证**: 需要 JWT Token (家长用户)

**请求参数**:
```json

  "gender": "male",
  "birthday": "2018-05-15",

  "phone": "13800138000",
  "interests": ["舞蹈", "绘画", "钢琴"],

```

**DTO验证规则**:
```typescript
class CreateChildDto {
  @IsNotEmpty({ message: '宝贝姓名不能为空' })
  @IsString()
  @MinLength(2, { message: '姓名至少2个字符' })
  @MaxLength(20, { message: '姓名最多20个字符' })
  name: string;

  @IsOptional()
  @IsString()
  avatar?: string;

  @IsOptional()
  @IsEnum(['male', 'female'])
  gender?: string;

  @IsOptional()
  @IsDateString()
  birthday?: string;

  @IsOptional()
  @IsInt()
  @Min(0)
  @Max(18)
  age?: number;

  @IsOptional()
  @IsString()
  phone?: string;

  @IsOptional()
  @IsArray()
  @IsString({ each: true })
  interests?: string[];

  @IsOptional()
  @IsString()
  @MaxLength(200)
  remark?: string;
}
```

**响应数据**:
```json
{
  "code": 200,
  "message": "success",
  "data": "9012345678901234"
}
```

**业务规则**:
- 每个用户最多添加 10 个宝贝
- 宝贝信息仅本人可见

**错误码**:
- `400`: 最多只能添加10个宝贝

## 9. 支付模块 (Payment)

### 9.1 创建预支付订单

**接口**: `POST /payment/prepay`  
**描述**: 创建微信支付预支付订单，获取前端调起支付所需参数  
**认证**: 需要 JWT Token

**请求参数**:
```json
{
  "order_id": "7890123456789012"
}
```

**响应数据**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "timeStamp": "1705484400",
    "nonceStr": "abc123",
    "package": "prepay_id=wx20260117100000xxx",
    "signType": "RSA",
    "paySign": "xxx"
  }
}
```

**业务逻辑**:
1. 验证订单存在且属于当前用户
2. 验证订单状态为 `pending`（待支付）
3. 调用微信支付 JSAPI 下单接口
4. 返回前端调起支付所需的签名参数

**前端使用**:
```typescript
// 获取支付参数
const payParams = await paymentApi.prepay({ order_id: orderId })

// 调起微信支付
wx.requestPayment({
  ...payParams,
  success: () => { /* 支付成功 */ },
  fail: () => { /* 支付取消/失败 */ }
})
```
