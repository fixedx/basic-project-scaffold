## 1. 架构概述

### 1.1 架构模式

采用 **分层架构 + 模块化设计**：

```
┌─────────────────────────────────────┐
│         Controller 层               │  HTTP 路由、参数验证
├─────────────────────────────────────┤
│          Service 层                 │  业务逻辑处理
├─────────────────────────────────────┤
│        Repository 层                │  数据访问封装
├─────────────────────────────────────┤
│          Entity 层                  │  数据模型定义
├─────────────────────────────────────┤
│        Database (PostgreSQL)        │  数据持久化
└─────────────────────────────────────┘

        横切关注点 (Cross-cutting)
┌──────────────────────────────────────┐
│ 认证授权 | 日志 | 异常 | 事务 | 缓存  │
└──────────────────────────────────────┘
```

### 1.2 设计原则

1. **单一职责原则（SRP）**: 每个模块只负责一个业务领域
2. **依赖注入（DI）**: 使用 NestJS 的 IoC 容器管理依赖
3. **面向接口编程**: Controller 依赖 Service，Service 依赖 Repository
4. **关注点分离**: 业务逻辑与基础设施分离
5. **统一基础类**: BaseEntity、BaseRepository 提供通用能力
6. **应用层关联**: 不使用 ORM 关联装饰器，在应用层手动加载关联数据

### 1.3 核心特性

- ✅ **统一响应格式**: 所有接口返回统一的 JSON 格式
- ✅ **统一异常处理**: 全局异常过滤器捕获所有错误
- ✅ **JWT 认证**: 基于 Token 的无状态认证
- ✅ **用户上下文**: nestjs-cls 管理请求级用户上下文
- ✅ **事务管理**: 装饰器实现声明式事务
- ✅ **软删除**: 所有表支持软删除，不物理删除数据
- ✅ **雪花ID**: 分布式唯一ID生成
- ✅ **枚举统一管理**: 枚举数据存储在数据库
- ✅ **多云存储**: 支持阿里云OSS、腾讯云COS

#### 4.1.1 AuthService

```typescript
@Injectable()
export class AuthService {
  constructor(
    private userRepository: UserRepository,
    private userInstitutionRepository: UserInstitutionRepository,
  ) {}

  // 微信登录
  async wechatLogin(code: string): Promise<LoginResult> {
    // 1. 用 code 换取 openid
    const openid = await this.getOpenidByCode(code);
    
    // 2. 查询或创建用户
    let user = await this.userRepository.findByOpenid(openid);
    if (!user) {
      user = await this.userRepository.create({ openid });
    }
    
    // 3. 生成 JWT Token
    const token = this.generateToken({ userId: user.id });
    
    return { token, user };
  }

  // 机构登录
  async institutionLogin(dto: InstitutionLoginDto): Promise<LoginResult> {
    // 1. 验证用户名密码
    const user = await this.userRepository.findByUsername(dto.username);
    if (!user || !this.verifyPassword(dto.password, user.password)) {
      throw new UnauthorizedException('用户名或密码错误');
    }
    
    // 2. 查询用户关联的机构
    const institutions = await this.userInstitutionRepository
      .findByUserId(user.id);
    
    // 3. 生成 Token（包含机构ID）
    const token = this.generateToken({
      userId: user.id,
      institutionId: institutions[0]?.institution_id
    });
    
    return { token, user, institutions };
  }
}
```

```typescript
@Injectable()
export class InstitutionService {
  constructor(
    private repository: InstitutionRepository,
    private userRepository: UserRepository,
    private userInstitutionRepository: UserInstitutionRepository,
    private userContextService: UserContextService,
    private dataSource: DataSource,
  ) {}

  // 创建机构（入驻）
  @Transactional()
  async create(dto: CreateInstitutionDto): Promise<string> {
    // 1. 创建用户账号
    const hashedPassword = await CryptoUtil.hashPassword(dto.password);
    const user = await this.userRepository.save({
      username: dto.username,
      password: hashedPassword,
      real_name: dto.real_name,
    });

    // 2. 创建机构
    const institution = await this.repository.save({
      name: dto.name,
      logo: dto.logo,
      license_no: dto.license_no,
      // ... 其他字段
      audit_status: 'pending',
    });

    // 3. 建立用户与机构的关联
    await this.userInstitutionRepository.save({
      user_id: user.id,
      institution_id: institution.id,
      role: 'owner',
    });

    return institution.id;
  }

  // 查询附近机构
  async findNearby(dto: FindNearbyDto): Promise<InstitutionEntity[]> {
    return this.repository.findNearby(
      dto.latitude,
      dto.longitude,
      dto.radius || 5, // 默认5km
      dto.categoryIds,
    );
  }

  // 审核机构
  async audit(id: string, dto: AuditDto): Promise<boolean> {
    const institution = await this.repository.findOneById(id);
    if (!institution) {
      throw new NotFoundException('机构不存在');
    }

    await this.repository.update(id, {
      audit_status: dto.status,
      audit_remark: dto.remark,
    });

    return true;
  }
}
```

#### 4.2.2 InstitutionRepository

```typescript
@Injectable()
export class InstitutionRepository extends BaseRepository<InstitutionEntity> {
  constructor(
    private dataSource: DataSource,
    private userCtx: UserContextService,
  ) {
    super(InstitutionEntity, dataSource.createEntityManager());
    this.setUserContextService(userCtx);
  }

  // 查询附近机构（使用 Haversine 公式）
  async findNearby(
    latitude: number,
    longitude: number,
    radius: number,
    categoryIds?: string[],
  ): Promise<InstitutionEntity[]> {
    let query = this.getQuery().andWhere(
      `(
        6371 * acos(
          cos(radians(:latitude)) * cos(radians(entity.latitude)) *
          cos(radians(entity.longitude) - radians(:longitude)) +
          sin(radians(:latitude)) * sin(radians(entity.latitude))
        )
      ) < :radius`,
      { latitude, longitude, radius },
    );

    if (categoryIds && categoryIds.length > 0) {
      query = query.andWhere(
        `entity.category_ids ?| ARRAY[:...categoryIds]`,
        { categoryIds },
      );
    }

    return query
      .andWhere('entity.audit_status = :status', { status: 'approved' })
      .orderBy('entity.created_at', 'DESC')
      .getMany();
  }
}
```

### 4.3 课程模块 (Course)

**职责**: 课程发布、SKU管理、位置搜索

**核心类**:

#### 4.3.1 CourseService

```typescript
@Injectable()
export class CourseService {
  constructor(
    private courseRepository: CourseRepository,
    private courseSkuRepository: CourseSkuRepository,
    private institutionRepository: InstitutionRepository,
    private userContextService: UserContextService,
    private dataSource: DataSource,
  ) {}

  // 创建课程
  @Transactional()
  async create(dto: CreateCourseDto): Promise<string> {
    // 1. 验证机构权限
    const userId = this.userContextService.getCurrentUserId();
    const hasPermission = await this.verifyInstitutionPermission(
      userId,
      dto.institution_id,
    );
    if (!hasPermission) {
      throw new ForbiddenException('无权限操作');
    }

    // 2. 创建课程
    const course = await this.courseRepository.save({
      institution_id: dto.institution_id,
      title: dto.title,
      type: dto.type,
      // ... 其他字段
      is_online: false, // 默认下架
    });

    // 3. 创建 SKU（含返现金额计算）
    if (dto.skus && dto.skus.length > 0) {
      for (const skuDto of dto.skus) {
        const sku = this.calculateSkuPrices(skuDto);
        await this.courseSkuRepository.save({
          course_id: course.id,
          ...sku,
        });
      }
    }

    return course.id;
  }

  // 计算 SKU 价格（返现金额）
  private calculateSkuPrices(dto: CreateSkuDto): any {
    const { total_price, cashback_type, cashback_value } = dto;
    let online_pay_price = 0;
    let offline_pay_price = 0;

    if (cashback_type === 'fixed') {
      // 固定返现
      online_pay_price = cashback_value;
      offline_pay_price = total_price - cashback_value;
    } else if (cashback_type === 'percentage') {
      // 百分比返现
      online_pay_price = total_price * (cashback_value / 100);
      offline_pay_price = total_price - online_pay_price;
    } else {
      // 无返现
      online_pay_price = total_price;
      offline_pay_price = 0;
    }

    return {
      ...dto,
      online_pay_price,
      offline_pay_price,
    };
  }

  // 上架课程
  async online(id: string): Promise<boolean> {
    const course = await this.courseRepository.findOneById(id);
    if (!course) {
      throw new NotFoundException('课程不存在');
    }

    // 检查机构是否已审核
    const institution = await this.institutionRepository.findOneById(
      course.institution_id,
    );
    if (institution.audit_status !== 'approved') {
      throw new BadRequestException('机构未通过审核，无法上架课程');
    }

    await this.courseRepository.update(id, { is_online: true });
    return true;
  }
}
```

#### 4.3.2 CourseRepository

```typescript
@Injectable()
export class CourseRepository extends BaseRepository<CourseEntity> {
  constructor(
    private dataSource: DataSource,
    private userCtx: UserContextService,
    private courseSkuRepository: CourseSkuRepository,
  ) {
    super(CourseEntity, dataSource.createEntityManager());
    this.setUserContextService(userCtx);
  }

  // 查询课程详情（包含 SKU）
  async findByIdWithSkus(id: string): Promise<CourseEntity | null> {
    // 1. 查询课程
    const course = await this.getQuery()
      .andWhere('entity.id = :id', { id })
      .getOne();

    if (!course) return null;

    // 2. 手动加载 SKU
    const skus = await this.courseSkuRepository
      .getQuery()
      .andWhere('entity.course_id = :courseId', { courseId: id })
      .orderBy('entity.sort', 'ASC')
      .getMany();

    course.skus = skus;
    return course;
  }

  // 批量加载 SKU（防止 N+1 查询）
  async loadSkusForCourses(courses: CourseEntity[]): Promise<void> {
    if (!courses || courses.length === 0) return;

    const courseIds = courses.map(c => c.id);
    const allSkus = await this.courseSkuRepository
      .getQuery()
      .andWhere('entity.course_id IN (:...courseIds)', { courseIds })
      .getMany();

    // 按 course_id 分组
    const skusByCourseId = new Map<string, any[]>();
    for (const sku of allSkus) {
      if (!skusByCourseId.has(sku.course_id)) {
        skusByCourseId.set(sku.course_id, []);
      }
      skusByCourseId.get(sku.course_id)!.push(sku);
    }

    // 组装到各个课程
    for (const course of courses) {
      course.skus = skusByCourseId.get(course.id) || [];
    }
  }
}
```

### 4.4 订单模块 (Order)

**职责**: 订单创建、支付、退款、统计

**核心类**:

#### 4.4.1 OrderService

```typescript
@Injectable()
export class OrderService {
  constructor(
    private orderRepository: OrderRepository,
    private courseRepository: CourseRepository,
    private courseSkuRepository: CourseSkuRepository,
    private institutionRepository: InstitutionRepository,
    private userContextService: UserContextService,
    private dataSource: DataSource,
  ) {}

  // 创建订单
  @Transactional()
  async create(dto: CreateOrderDto): Promise<string> {
    const userId = this.userContextService.getCurrentUserId();

    // 1. 验证课程和 SKU
    const course = await this.courseRepository.findOneById(dto.course_id);
    if (!course || !course.is_online) {
      throw new BadRequestException('课程不存在或已下架');
    }

    const sku = await this.courseSkuRepository.findOneById(dto.sku_id);
    if (!sku || sku.course_id !== dto.course_id) {
      throw new BadRequestException('SKU不存在或不属于该课程');
    }

    // 2. 检查库存
    if (sku.stock !== -1 && sku.stock <= 0) {
      throw new BadRequestException('库存不足');
    }

    // 3. 获取机构信息
    const institution = await this.institutionRepository.findOneById(
      course.institution_id,
    );

    // 4. 生成订单号
    const orderNo = this.generateOrderNo();

    // 5. 创建订单（保存快照）
    const order = await this.orderRepository.save({
      order_no: orderNo,
      user_id: userId,
      institution_id: course.institution_id,
      course_id: dto.course_id,
      sku_id: dto.sku_id,
      original_price: sku.total_price,
      paid_amount: sku.total_price, // 实际可能有优惠
      cashback_amount: sku.online_pay_price,
      status: 'pending',
      institution_snapshot: {
        id: institution.id,
        name: institution.name,
        contact_phone: institution.contact_phone,
        address: `${institution.province}${institution.city}${institution.district}${institution.address}`,
      },
      course_snapshot: {
        id: course.id,
        title: course.title,
        cover_img: course.cover_url,
        type: course.type,
      },
      sku_snapshot: {
        id: sku.id,
        name: sku.name,
        total_price: sku.total_price,
        total_lessons: sku.total_lessons,
      },
    });

    // 6. 扣减库存
    if (sku.stock !== -1) {
      await this.courseSkuRepository.decreaseStock(dto.sku_id, 1);
    }

    return order.id;
  }

  // 确认支付
  @Transactional()
  async confirmPayment(id: string, dto: ConfirmPaymentDto): Promise<boolean> {
    const order = await this.orderRepository.findOneById(id);
    if (!order) {
      throw new NotFoundException('订单不存在');
    }

    if (order.status !== 'pending') {
      throw new BadRequestException('订单状态不正确');
    }

    await this.orderRepository.update(id, {
      status: 'paid',
      payment_method: dto.payment_method,
      paid_at: new Date(),
    });

    return true;
  }

  // 申请退款
  async applyRefund(id: string, dto: ApplyRefundDto): Promise<boolean> {
    const order = await this.orderRepository.findOneById(id);
    if (!order) {
      throw new NotFoundException('订单不存在');
    }

    if (order.status !== 'paid') {
      throw new BadRequestException('只有已支付订单可以申请退款');
    }

    await this.orderRepository.update(id, {
      status: 'refunding',
      refund_reason: dto.reason,
    });

    return true;
  }

  // 处理退款
  @Transactional()
  async processRefund(
    id: string,
    dto: ProcessRefundDto,
  ): Promise<boolean> {
    const order = await this.orderRepository.findOneById(id);
    if (!order) {
      throw new NotFoundException('订单不存在');
    }

    if (order.status !== 'refunding') {
      throw new BadRequestException('订单不在退款中');
    }

    if (dto.approve) {
      // 同意退款
      await this.orderRepository.update(id, {
        status: 'refunded',
        refund_amount: dto.refund_amount || order.paid_amount,
        refund_at: new Date(),
      });

      // 恢复库存
      await this.courseSkuRepository.increaseStock(order.sku_id, 1);
    } else {
      // 拒绝退款
      await this.orderRepository.update(id, {
        status: 'paid',
        refund_reason: null,
      });
    }

    return true;
  }

  // 生成订单号
  private generateOrderNo(): string {
    const timestamp = Date.now();
    const random = Math.floor(Math.random() * 10000).toString().padStart(4, '0');
    return `${timestamp}${random}`;
  }
}
```

### 5.2 BaseRepository

**职责**: 提供通用的数据访问方法

```typescript
import { Repository, EntityTarget, EntityManager, SelectQueryBuilder } from 'typeorm';
import { BaseEntity } from '@/common/entities/base.entity';
import { UserContextService } from '@/common/services/user-context.service';

export class BaseRepository<T extends BaseEntity> extends Repository<T> {
  private userContextService: UserContextService;

  constructor(
    entity: EntityTarget<T>,
    manager: EntityManager,
  ) {
    super(entity, manager);
  }

  // 设置用户上下文服务（必须在构造后调用）
  setUserContextService(service: UserContextService) {
    this.userContextService = service;
  }

  // 获取基础查询（自动过滤软删除，按ID降序）
  getQuery(alias = 'entity'): SelectQueryBuilder<T> {
    return this.createQueryBuilder(alias)
      .where(`${alias}.is_delete = :isDelete`, { isDelete: false })
      .orderBy(`${alias}.id`, 'DESC');
  }

  // 获取激活记录的查询
  getQueryWithActive(alias = 'entity'): SelectQueryBuilder<T> {
    return this.getQuery(alias)
      .andWhere(`${alias}.is_active = :isActive`, { isActive: true });
  }

  // 获取当前用户创建的数据
  getQueryWithMyData(alias = 'entity'): SelectQueryBuilder<T> {
    const userId = this.userContextService.getCurrentUserId();
    return this.getQuery(alias)
      .andWhere(`${alias}.created_by = :userId`, { userId });
  }

  // 查询所有激活记录
  async findAllActive(): Promise<T[]> {
    return this.getQueryWithActive().getMany();
  }

  // 根据ID查询（过滤软删除）
  async findOneById(id: string): Promise<T | null> {
    return this.getQuery()
      .andWhere('entity.id = :id', { id })
      .getOne();
  }

  // 分页查询（兼容模式）
  async paginate(
    page?: number,
    pageSize?: number,
    options?: any,
  ): Promise<any> {
    const query = this.getQuery();

    // 应用额外条件
    if (options?.where) {
      Object.keys(options.where).forEach(key => {
        query.andWhere(`entity.${key} = :${key}`, {
          [key]: options.where[key],
        });
      });
    }

    // 分页模式
    if (page !== undefined && pageSize !== undefined) {
      const skip = (page - 1) * pageSize;
      const [data, total] = await query
        .skip(skip)
        .take(pageSize)
        .getManyAndCount();

      return {
        data,
        total,
        page,
        pageSize,
        totalPages: Math.ceil(total / pageSize),
      };
    }

    // 不分页模式
    return query.getMany();
  }

  // 软删除
  async softRemoveById(id: string): Promise<boolean> {
    const userId = this.userContextService.getCurrentUserIdOrNull();
    await this.update(id as any, {
      is_delete: true,
      updated_by: userId,
    } as any);
    return true;
  }

  // 恢复软删除
  async restoreById(id: string): Promise<boolean> {
    const userId = this.userContextService.getCurrentUserIdOrNull();
    await this.update(id as any, {
      is_delete: false,
      updated_by: userId,
    } as any);
    return true;
  }

  // 保存前自动填充创建人/更新人
  async save<E extends T>(entity: E | E[]): Promise<E | E[]> {
    const userId = this.userContextService.getCurrentUserIdOrNull();
    
    if (Array.isArray(entity)) {
      entity.forEach(e => {
        if (!e.id) {
          e.created_by = userId;
        }
        e.updated_by = userId;
      });
    } else {
      if (!entity.id) {
        entity.created_by = userId;
      }
      entity.updated_by = userId;
    }

    return super.save(entity);
  }
}
```

**特点**:
- ✅ 自动过滤软删除数据
- ✅ 自动按ID降序排序
- ✅ 自动填充创建人/更新人
- ✅ 支持分页兼容模式
- ✅ 提供常用查询方法

### 6.2 HTTP异常过滤器

**职责**: 统一异常响应格式

```typescript
import {
  ExceptionFilter,
  Catch,
  ArgumentsHost,
  HttpException,
  HttpStatus,
} from '@nestjs/common';
import { Response } from 'express';

@Catch(HttpException)
export class HttpExceptionFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();
    const status = exception.getStatus();
    const exceptionResponse = exception.getResponse();

    const message =
      typeof exceptionResponse === 'string'
        ? exceptionResponse
        : (exceptionResponse as any).message || '服务器错误';

    response.status(status).json({
      code: status,
      message: Array.isArray(message) ? message[0] : message,
      data: null,
    });
  }
}
```

### 6.3 日志拦截器

```typescript
import {
  Injectable,
  NestInterceptor,
  ExecutionContext,
  CallHandler,
  Logger,
} from '@nestjs/common';
import { Observable } from 'rxjs';
import { tap } from 'rxjs/operators';

@Injectable()
export class LoggingInterceptor implements NestInterceptor {
  private readonly logger = new Logger('HTTP');

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const request = context.switchToHttp().getRequest();
    const { method, url, body, query } = request;
    const now = Date.now();

    this.logger.log(`→ ${method} ${url}`);
    if (Object.keys(query).length > 0) {
      this.logger.debug(`Query: ${JSON.stringify(query)}`);
    }
    if (Object.keys(body).length > 0) {
      this.logger.debug(`Body: ${JSON.stringify(body)}`);
    }

    return next.handle().pipe(
      tap(() => {
        const duration = Date.now() - now;
        this.logger.log(`← ${method} ${url} ${duration}ms`);
      }),
    );
  }
}
```
