# API 接口文档 - 管理与运营

> **版本**: v1.0  
> **最后更新**: 2026-03-20  
> **覆盖模块**: 管理后台 (Admin)、公告 (Announcement)、用户反馈 (Feedback)、邀友让利 (Invite)

---

## 接口规范

### 请求格式

- **Content-Type**: `application/json`
- **Base URL**: `http://localhost:8888/api`
- **认证方式**: Bearer Token（在 Header 中携带 `Authorization: Bearer <token>`）

### 响应格式

```json
{
  "code": 200,
  "data": {},
  "message": "success"
}
```

### 权限说明

| 标记 | 说明 |
|------|------|
| 🔓 公开 | 无需登录即可访问 |
| 🔑 需登录 | 需要有效的 Bearer Token |
| 👑 管理员 | 需要 admin 角色 Token |
| 🏢 机构端 | 需要 institution 角色 Token |

## 2. 公告模块 (Announcement)

### 2.1 创建公告

👑 **需要管理员权限**

**请求**
```
POST /api/announcement
```

**请求体**

```json
{
  "title": "平台正式上线公告",
  "content": "欢迎使用兴趣班平台！我们汇聚了众多优质培训机构...",
  "type": "system",
  "status": "active",
  "priority": 1,
  "start_time": "2026-03-20T00:00:00.000Z",
  "end_time": null
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | ✅ | 公告标题 |
| content | string | ✅ | 公告内容 |
| type | string | - | 公告类型，如 `system` / `activity` / `notice` |
| status | string | - | 状态：`active`（发布）/ `inactive`（草稿），默认 `active` |
| priority | number | - | 优先级（数字越大越靠前，默认 0） |
| start_time | string | - | 生效时间（ISO 日期字符串） |
| end_time | string | - | 失效时间（ISO 日期字符串） |

**响应示例**

```json
{
  "code": 200,
  "data": "272938442025984001",
  "message": "success"
```

## 附录

### A. 公告状态说明

| 状态 | 说明 |
|------|------|
| `active` | 已发布，对用户可见 |
| `inactive` | 草稿，对用户不可见 |

### B. 反馈状态流转

```
提交 → pending → processing → resolved
                            ↘ closed（管理员关闭）
```

| 状态 | 说明 |
|------|------|
| `pending` | 待处理 |
| `processing` | 处理中 |
| `resolved` | 已解决 |
| `closed` | 已关闭 |

### C. 邀友让利规则

```
返现计算：
  返现总金额 = 订单金额 × 课程返现比例（3-15%，默认10%）
  邀请人获得 = 返现总金额 × 分享比例（0-100%，默认50%）
  被邀请人获得 = 返现总金额 × (1 - 分享比例)

返现解锁：
  按上课进度解锁，上完1节课解锁 1/总课时 比例的返现金额

提现规则：
  最低提现金额：50元（管理员可通过 withdraw_min_amount 配置项调整）
  提现无需人工审核，提交后直接转入登录微信零钱，实时到账
```

### D. 管理员登录方式

管理员账号使用用户名密码登录，不使用手机号/微信登录：

```http
POST /api/auth/admin-login

{
  "username": "admin",
  "password": "admin123"
}
```

响应中包含 `token`，用于所有管理员权限接口。
