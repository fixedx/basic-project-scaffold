## 1. 课程模块 (Course)

### 1.1 创建课程

**接口**: `POST /courses`  
**描述**: 机构发布新课程  
**认证**: 需要 JWT Token + 机构权限

**请求参数**:
```json
{
  "institution_id": "2345678901234567",
  "title": "钢琴基础课",
  "subtitle": "零基础入门，专业老师指导",
  "cover_url": "https://xxx.com/piano-cover.jpg",
  "slider_imgs": [
    "https://xxx.com/piano-1.jpg",
    "https://xxx.com/piano-2.jpg"
  ],
  "category_code": "piano",
  "type": "standard",
  "introduction": "适合5-12岁儿童学习钢琴...",
  "detail": "<p>课程详细介绍...</p>",
  "min_age": 5,
  "max_age": 12,
  "tags": ["钢琴", "入门", "小班"],
  "skus": [
    {
      "name": "10课时包",
      "total_lessons": 10,
      "total_price": 1000.00,
      "cashback_type": "percentage",
      "cashback_value": 10,
      "stock": 50
    },
    {
      "name": "20课时包",
      "total_lessons": 20,
      "total_price": 1800.00,
      "cashback_type": "fixed",
      "cashback_value": 200,
      "stock": 30
    }
  ]
}
```

**DTO验证规则**:
```typescript
class CreateCourseDto {
  @IsNotEmpty({ message: '机构ID不能为空' })
  @IsString()
  institution_id: string;

  @IsNotEmpty({ message: '课程标题不能为空' })
  @IsString()
  @MaxLength(100)
  title: string;

  @IsOptional()
  @IsString()
  @MaxLength(200)
  subtitle?: string;

  @IsOptional()
  @IsString()
  cover_url?: string;

  @IsOptional()
  @IsArray()
  slider_imgs?: string[];

  @IsOptional()
  @IsString()
  category_code?: string;

  @IsNotEmpty({ message: '课程类型不能为空' })
  @IsIn(['standard', 'trial'])
  type: string;

  @IsOptional()
  @IsString()
  introduction?: string;

  @IsOptional()
  @IsString()
  detail?: string;

  @IsOptional()
  @IsInt()
  @Min(0)
  min_age?: number;

  @IsOptional()
  @IsInt()
  @Min(0)
  max_age?: number;

  @IsOptional()
  @IsArray()
  tags?: string[];

  @IsNotEmpty({ message: '至少添加一个SKU' })
  @IsArray()
  @ArrayMinSize(1)
  @ValidateNested({ each: true })
  @Type(() => CreateCourseSkuDto)
  skus: CreateCourseSkuDto[];
}

class CreateCourseSkuDto {
  @IsNotEmpty({ message: 'SKU名称不能为空' })
  @IsString()
  name: string;

  @IsNotEmpty({ message: '总课时数不能为空' })
  @IsInt()
  @Min(1)
  total_lessons: number;

  @IsNotEmpty({ message: '课程总价不能为空' })
  @IsNumber()
  @Min(0)
  total_price: number;

  @IsNotEmpty({ message: '返现类型不能为空' })
  @IsIn(['percentage', 'fixed', 'none'])
  cashback_type: string;

  @IsNotEmpty({ message: '返现值不能为空' })
  @IsNumber()
  @Min(0)
  cashback_value: number;

  @IsOptional()
  @IsInt()
  stock?: number;

  @IsOptional()
  @IsInt()
  sort?: number;
}
```

**响应数据**:
```json
{
  "code": 200,
  "message": "success",
  "data": "3456789012345678"
}
```

**业务逻辑**:
1. 验证机构权限（用户必须是该机构的成员）
2. 验证机构审核状态（必须已通过审核）
3. 创建课程记录（默认下架状态 is_online = false）
4. 创建SKU记录，**自动计算返现金额**：
   - 固定返现：`online_pay_price = cashback_value`, `offline_pay_price = total_price - cashback_value`
   - 百分比返现：`online_pay_price = total_price × (cashback_value / 100)`, `offline_pay_price = total_price - online_pay_price`
   - 无返现：`online_pay_price = total_price`, `offline_pay_price = 0`
5. 事务提交，返回课程ID

**错误码**:
- `403`: 无权限操作
- `400`: 机构未通过审核
- `400`: 参数验证失败

### 1.2 获取课程列表

**接口**: `GET /courses`  
**描述**: 获取课程列表（支持筛选和分页）  
**认证**: 不需要（公开接口）

**请求参数**:
```
?page=1
&pageSize=20
&institution_id=2345678901234567
&type=standard
&category_code=piano
&min_age=5
&max_age=12
&is_online=true
&keyword=钢琴
&sort=sales
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | number | 否 | 页码 |
| pageSize | number | 否 | 每页数量 |
| institution_id | string | 否 | 机构ID筛选 |
| type | string | 否 | 课程类型（standard/trial） |
| category_code | string | 否 | 分类代码 |
| min_age | number | 否 | 最小适龄 |
| max_age | number | 否 | 最大适龄 |
| is_online | boolean | 否 | 是否上架 |
| keyword | string | 否 | 关键字搜索（标题） |
| sort | string | 否 | 排序方式（sales-销量, rating-评分, price-价格, time-时间） |

**响应数据**:

### 1.4 更新课程

**接口**: `PUT /courses/:id`  
**描述**: 更新课程信息  
**认证**: 需要 JWT Token + 机构权限

**路径参数**:

```json
{
  "title": "钢琴进阶课",
  "subtitle": "更新后的副标题",
  "cover_url": "https://xxx.com/new-cover.jpg",
  "introduction": "更新后的简介...",
  "detail": "<p>更新后的详情...</p>",
  "tags": ["钢琴", "进阶"]

```

```json

  "message": "success",
  "data": true

```

**业务逻辑**:
1. 验证机构权限
2. 更新课程信息
3. 不影响已生成的订单（订单使用快照）

## 2. 教室模块 (Classroom)

### 2.1 创建教室

**接口**: `POST /classroom`  
**描述**: 机构创建教室  
**认证**: 需要 JWT Token + 机构权限

**请求参数**:
```json
{
  "institution_id": "2345678901234567",
  "name": "201教室",
  "capacity": 20,
  "area": 50.00,
  "floor": "2楼",
  "facilities": ["投影仪", "空调", "白板", "钢琴"],
  "status": "available",
  "remark": "适合钢琴小班课"
}
```

**DTO验证规则**:
```typescript
class CreateClassroomDto {
  @IsNotEmpty()
  @IsString()
  institution_id: string;

  @IsNotEmpty({ message: '教室名称不能为空' })
  @IsString()
  name: string;

  @IsOptional()
  @IsInt()
  @Min(1)
  capacity?: number;

  @IsOptional()
  @IsNumber()
  @Min(0)
  area?: number;

  @IsOptional()
  @IsString()
  floor?: string;

  @IsOptional()
  @IsArray()
  facilities?: string[];

  @IsOptional()
  @IsIn(['available', 'maintenance', 'disabled'])
  status?: string;

  @IsOptional()
  @IsString()
  remark?: string;
}
```

**响应数据**:
```json
{
  "code": 200,
  "message": "success",
  "data": "6789012345678901"
}
```

**业务逻辑**:
1. 验证机构权限
2. 验证教室名称在机构内唯一
3. 创建教室记录

**错误码**:
- `403`: 无权限操作
- `400`: 教室名称已存在

## 4. 排课模块 (Schedule)

### 4.1 创建排课

**接口**: `POST /schedule`  
**描述**: 为课程安排上课时间、教师和教室  
**认证**: 需要 JWT Token + 机构权限

**请求参数**:
```json
{
  "institution_id": "2345678901234567",
  "course_id": "3456789012345678",
  "teacher_id": "9012345678901234",
  "classroom_id": "6789012345678901",
  "start_time": "2026-01-10T14:00:00.000Z",
  "end_time": "2026-01-10T15:30:00.000Z",
  "day_of_week": "5",
  "max_students": 10
}
```

**DTO验证规则**:
```typescript
class CreateScheduleDto {
  @IsNotEmpty()
  @IsString()
  institution_id: string;

  @IsNotEmpty({ message: '课程ID不能为空' })
  @IsString()
  course_id: string;

  @IsNotEmpty({ message: '教师ID不能为空' })
  @IsString()
  teacher_id: string;

  @IsNotEmpty({ message: '教室ID不能为空' })
  @IsString()
  classroom_id: string;

  @IsNotEmpty({ message: '开始时间不能为空' })
  @IsDateString()
  start_time: string;

  @IsNotEmpty({ message: '结束时间不能为空' })
  @IsDateString()
  end_time: string;

  @IsNotEmpty({ message: '星期不能为空' })
  @IsIn(['1', '2', '3', '4', '5', '6', '7'])
  day_of_week: string;

  @IsNotEmpty({ message: '最大学生数不能为空' })
  @IsInt()
  @Min(1)
  max_students: number;
}
```

**响应数据**:
```json
{
  "code": 200,
  "message": "success",
  "data": "1234567890123456"
}
```

**业务逻辑**:
1. 验证机构权限
2. 验证课程、教师、教室都属于该机构
3. **检测时间冲突**：
   - 同一教师在同一时间段不能有多个排课
   - 同一教室在同一时间段不能有多个排课
4. 验证开始时间 < 结束时间
5. 创建排课记录

**时间冲突检测SQL**:
```sql
-- 检测教师冲突
SELECT * FROM schedules 
WHERE teacher_id = ? 
  AND day_of_week = ?
  AND (
    (start_time <= ? AND end_time > ?) OR 
    (start_time < ? AND end_time >= ?)
  )
  AND is_delete = false;

-- 检测教室冲突
SELECT * FROM schedules 
WHERE classroom_id = ? 
  AND day_of_week = ?
  AND (
    (start_time <= ? AND end_time > ?) OR 
    (start_time < ? AND end_time >= ?)
  )
  AND is_delete = false;
```

**错误码**:
- `403`: 无权限操作
- `400`: 教师时间冲突
- `400`: 教室时间冲突
- `400`: 开始时间必须早于结束时间
